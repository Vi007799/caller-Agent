# Builder Call Agent

Voice calling agent + dashboard + 3D website for a real-estate builder.

- Dashboard: `/admin`    - Website: `/`    - Setup: see `GO-LIVE.md`    - Handover to the builder: see `CLIENT-HANDOFF.md`

Quick start (Windows): `copy .env.example .env`, fill it in, then `npm run start:env`.
Text-only demo of the conversation: `npm run demo`. Tests: `npm test`.
